# 手柄优化

**作者**：MniShark  
**版本**：1.0.0  
**游戏**：星露谷物语（Stardew Valley）  
**依赖**：SMAPI 4.0.0 或更高版本  
**可选依赖**：Generic Mod Config Menu（GMCM，用于游戏内配置）

---

## 功能概述

本 Mod 专为手柄玩家优化操作体验，提供以下三项核心功能：

### 1. 自定义按键抑制
- 你可以指定任意手柄按键（或按键组合），其 **原版功能将被完全禁用**。
- 例如：可禁用手柄左摇杆按下触发的奔跑切换，或禁用 D-Pad 上下键等。
- 被抑制的按键不会触发任何游戏内行为，避免误触。

### 2. 一键丢弃物品（背包内）
- 在打开背包（物品栏）时，**拿起物品后按下指定按键**，即可直接将物品丢到地上。
- 遵循原版掉落规则：
  - **武器**（剑、锤、匕首等）可以丢弃。
  - **工具**（锄头、斧头、喷壶等）**默认不可丢弃**，但以下特殊工具允许丢弃：
    - 钓鱼竿（FishingRod）
    - 自动采集器（AutoGrabber）
    - 加热器（Heater）
    - 淘金盘（CopperPan）
- 如果物品无法丢弃，会有日志提示（并在游戏中不执行任何操作）。

### 3. B 键智能关闭菜单（增强）
- 按下手柄 **B 键**（即 `ControllerB`）时：
  1. 如果当前在背包界面且**光标上正拿着物品**（悬空物品）：
     - 首先尝试将物品放回**原槽位**（即你拿起它时的位置）；
     - 若原槽位已被占用，则寻找第一个空位放入；
     - 若背包已满，则物品**自动掉落在地上**，避免物品丢失。
  2. **关闭当前打开的所有菜单**（背包、商店、对话等），相当于原版 B 键的关闭功能。
- 此功能 **取代** 原版 B 键的默认行为，但保留了关闭菜单的作用，同时增加了悬空物品的智能处理。

## 配置说明

本 Mod 支持通过 **Generic Mod Config Menu**（GMCM）在游戏内实时调整配置。若未安装 GMCM，则使用默认配置，并可手动编辑 `config.json` 文件。

### 配置文件位置
`Stardew Valley/Mods/手柄优化/config.json`

### 配置项详解

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `SuppressedButtons` | `KeybindList` | 空列表 | 需要抑制的按键列表。支持单个按键或组合键（如 `LeftControl + DPadDown`）。所有在此列表中的按键，其原版功能将被屏蔽。 |
| `DropItemButton` | `SButton` | `DPadDown` | 在背包中拿起物品后，按下此键即可丢弃该物品。 |

### 修改配置（无 GMCM）
手动编辑 `config.json` 示例：
```json
{
  "SuppressedButtons": {
    "Keybinds": [
      { "Buttons": [ "LeftStick" ] },
      { "Buttons": [ "DPadUp", "DPadDown" ] }
    ]
  },
  "DropItemButton": "DPadDown"
}
